以下是veo3生成视频API接口：
接口地址：https://api.wuyinkeji.com/api/video/veoPlus

返回格式：application/json

请求方式：HTTPPOST

请求示例：https://api.wuyinkeji.com/api/video/veoPlus

请求HEADER：
名称	值
Content-Type	application/json;charset:utf-8;
Authorization	接口密钥,在控制台->密钥管理查看
请求参数说明：


名称	必填	类型	示例值	说明
model	是	string	veo3	模型名称：veo3
prompt	是	string	小猫钓鱼 竖屏	指令
type

是	string	
text2video

类型：
text2video和img2video

img_url	否	string或array	
["https:/xx.com/demo.jpg","http://xxx.com/xxx.png"]

当类型为img2video必传（支持外网访问并下载的图片链接，暂时只支持1张）
ratio	否	string	16:9	尺寸:16:9和9:16




返回参数说明：
名称	类型	说明
code	int	状态码
msg	string	状态信息
data	object	请求结果数据集
返回示例：
{
"msg": "成功",
-"data": {
"id": 111
},
"code": 200
}


以下是veo3视频生成结果查询接口：
接口地址：https://api.wuyinkeji.com/api/video/veoDetail

返回格式：application/json

请求方式：HTTPGET

请求示例：https://api.wuyinkeji.com/api/video/veoDetail?key=你的密钥&id=1

请求HEADER：
名称	值
Content-Type	application/json;charset:utf-8;
Authorization	接口密钥,在控制台->密钥管理查看
请求参数说明：


名称	必填	类型	示例值	说明
id	是	int	1	视频ID




返回参数说明：
名称	类型	说明
code	int	状态码
msg	string	状态信息
data	object	请求结果数据集
data.id	int	视频ID
data.content	string	生成的视频地址
data.status	int	状态，0:排队中，1:成功，2:失败，3:生成中
data.fail_reason	string	失败原因
data.created_at	string	创建时间
data.updated_at	string	更新时间
返回示例：
{
"msg": "成功",
-"data": {
"id": 1352,
"content": "https://openpt.tos-cn-shanghai.volces.com/veo/20250823/76b18e9bc6834d1990ec034ae43a177a.mp4",
"status": 1,
"fail_reason": "",
"created_at": "2025-08-23 10:37:17",
"updated_at": "2025-08-23 10:39:10"
},
"code": 200
}
